**Goal:** Find formula, source, or trust objections before seed outreach. This review is not a product feedback request.

```txt
I'm validating the methodology behind a BTC market-cap flippening image.

Please try to break the methodology, not the product:
https://btcbeats-ten.vercel.app/methodology?ref=methodology_reviewer_<id>

Questions:
1. Is any formula wrong or misleading?
2. Is any source unacceptable for a public chart?
3. Is any assumption missing or underexplained?
4. Would you cite this methodology if you used the image?

If something is wrong, please name the exact issue. A general "looks fine" is less useful than one concrete objection.
```

## Objection Classes

- `formula`: Metric calculation is wrong or misleading.
- `source`: Data source is not credible enough.
- `assumption`: Supply, delay, market-cap, or 24h window assumption is underexplained.
- `citation`: Reviewer would not cite this publicly.
- `copy`: Explanation is accurate but unclear.

## Pass Criteria

- No unresolved `formula` objection.
- No unresolved `source` objection that blocks public citation.
- At least one reviewer says the methodology is citeable or defensible.
